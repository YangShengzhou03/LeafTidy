## 你是否也有这样的烦恼

攒了三年的旅行照片，存在二十几个文件夹里，想找一个西湖边的夕阳照，翻了二十分钟没找到。手机连拍了五十张，张张都留着，硬盘红了，想删又不知道删哪个。更崩溃的是，你发在社交平台上的照片，别人下载右键一看EXIF，你家的GPS坐标、用什么手机拍的、什么时候拍的，全暴露了。你花大价钱买的数码设备，攒了几年的回忆，它们本该被好好保管，而不是沦为数字垃圾。这不是你的错，是你缺一个真正好用的工具。

轻羽归档就是为了这个而生的。

打开软件，添加文件夹，选择功能，预览确认，一键执行，不满意就撤回。整个过程不需要联网，不需要注册账号，不需要把任何文件上传到云端。你的数据只在你自己的电脑上，永远。

## 智能文件整理

你受够了手动建文件夹、复制粘贴的日子。智能文件整理把这个过程变成全自动。添加待整理的目录之后，选择分类标签，拖拽组合归档层级，软件就会自动计算每个文件该去哪个文件夹，安全移动或复制过去。

标签支持文件类型、年份、月份、日期、省份、城市、区县、地点、相机品牌、相机型号、扩展名、文件大小，一共十二个维度。时间来源可以选文件的修改时间、创建时间，或者照片EXIF里的拍摄日期。路径构建器会实时预览你将要生成的目录结构，拖拽标签的顺序就是最终文件夹的层级顺序。归档过程中实时显示成功数和失败数，遇到重名文件自动加序号，绝对不会覆盖你已有的文件。

想象一下，你电脑里散落在桌面、下载、U盘里上千张照片，一键之后变成浙江省/杭州市/滨江区/2026/06/15/这样井井有条的目录结构。那个感觉，真的很爽。

## 批量重命名

几百个文件，文件名乱七八糟，IMG_001、截图20240101、微信图片_20231225192711，根本没法看。批量重命名功能内置可视化模板构建器，通过点击标签和分隔符自由组合你要的命名规则，右边实时预览改名之后的效果。

命名标签包括日期、时间、年份、月份、日、文件类型、原文件名、扩展名、序号、省份、城市、区县、地点、相机品牌、相机型号、文件大小，一共十六个维度。分隔符支持下划线、横线、空格、点号四种。序号起始值可以自定义，比如从1开始或者从100开始。时间来源同样可选修改时间、创建时间、拍摄日期。

你甚至可以组合出"江西省_南昌市_2026-06-15_西湖_001"这样信息量丰富的文件名。拖拽标签加入模板，点击标签即可移除，所见即所得。处理结果复制到输出目录，源文件原封不动，零风险。

## 重复文件清理

你的硬盘里有多少重复文件，你根本不知道。下载了三遍的电影，转发了五次的表情包，手机导出的重复照片，它们正在悄悄吞噬你的磁盘空间。重复文件清理提供四种检测方式，让重复文件无处遁形。

MD5校验精确匹配文件内容，即使文件名不同、格式转了一样能揪出来。文件大小快速检测，扫描速度最快。双重校验结合MD5和文件大小，是最准确的检测方式。相似照片检测基于dHash算法，专门识别连拍或重复拍摄的照片，自动保留最清晰的一张，其余标记为可清理。

清理方式支持移至回收站、移动到指定目录、彻底删除三种。扫描结果按重复组展示，显示MD5值、文件大小、重复数量，统计总共浪费了多少磁盘空间。支持全选重复项一键清理，也可以逐组选择精细操作。默认保留最早的一份文件，避免误删。增量更新机制保证清理之后不需要每次全量重扫。

有人说他清出了47GB的重复文件。47GB，相当于十几部高清电影的空间。你的硬盘里藏着多少这样的惊喜，扫描一次就知道了。

## AI 智能分类

这是轻羽归档最强大的功能，用了本地AI模型，不需要联网，纯离线运行，所有AI推理都在你自己的电脑上完成。

提供三种分类模式。内容分类使用YOLOv8n-cls或YOLOv8s-cls ONNX模型进行离线图像分类，自动把照片按内容归入不同类别。人物分组使用YuNet人脸检测配合SFace人脸识别，自动聚类出不同人物，同一个人的照片归在一起。混合模式先识别出有人脸的照片按人物分组，其余的照片按内容分类，两种能力一次搞定。

置信度阈值可选宽松、标准、严格、极严格四档，内置快速模型和精准模型随时切换，同时支持添加自定义ONNX格式模型。人物管理支持给识别出的人物改名、把两个人的照片合并、按人物归档到独立文件夹。分类结果通过ECharts环形图可视化展示各类别分布。

给一个文件夹扔进去一千张照片，出来的结果是"张三"、"李四"、"风景"、"美食"、"宠物"……这样的子文件夹。你说这个能力值多少钱，我一分不取。

## 照片脱敏

你可能不知道，你发到朋友圈的每一张照片，都可能携带拍摄时间、GPS定位坐标、相机品牌型号、XMP标记、Photoshop编辑记录。这些信息叫EXIF元数据，肉眼看不见，但任何人在电脑上右键查看属性就能一览无余。你的家在哪，你用什么手机，你今天去了哪里，全写在照片里。

照片脱敏功能把这些隐私信息一键清除，在保留照片原始画质的前提下，让你的照片变得干干净净。你可以自由选择清除哪些项，EXIF拍摄信息、GPS位置、相机品牌型号、XMP标记、Photoshop信息，五项独立勾选，需要清哪个就勾哪个。批量处理，实时显示进度，处理完成后展示成功和失败明细。

处理结果复制到输出目录，源文件保留，支持JPG格式照片。发照片给朋友、发社交平台之前，先脱个敏，这是对自己最基本的保护。

## 写入地理信息

有些老照片或者经过编辑的照片丢失了GPS信息，没法在地图上回顾，也没法按地点分类整理。写入地理信息功能可以为这些照片补写GPS坐标，精度支持6位小数。

你可以手动输入经纬度，也可以从预设地点快速填充，内置吉安、南昌、杭州三个常用地点一键写入。内置离线地名库涵盖中国行政区划与地名数据库，支持反向地理编码查询，输入坐标自动查询对应地址信息，无需联网，纯本地计算。批量写入，实时显示进度。

处理结果复制到输出目录，源文件保留，支持JPG格式照片。

![写入地理信息界面](https://gitee.com/Yangshengzhou/leaf-tidy/raw/master/assets/LeafTidy-write-gps.png)

## 修复拍摄时间

有些照片的拍摄时间丢失了，相册里它们被排到不知道什么位置，时间线全乱了。修复拍摄时间功能可以为这些照片补写EXIF拍摄时间，让它们回到正确的位置。

时间来源有两种方式。从文件名识别时间，比如IMG_20240115_143022或者Screenshot_2024-01-15-14-30-22这类常见命名，软件自动识别其中的日期和时间写入EXIF。也可以手动指定统一时间，所有选中的照片都写入你指定的那个时间，日期时间选择器精确到秒。批量处理，实时显示进度。

处理结果复制到输出目录，源文件保留，支持JPG格式照片。修完之后打开相册，所有照片按正确的时间线排列，那种秩序感，只有经历过混乱的人才懂。

## 低质图片清理

手机里三千张照片，有多少是模糊的、是小尺寸的截图、是闭着眼睛的合照？它们占据了宝贵的存储空间，却没有任何保留价值。

低质图片清理功能自动检测并清理这些图片。模糊检测基于拉普拉斯方差算法，识别失焦或者运动模糊的照片。小尺寸检测识别分辨率过低的图片。截图检测识别屏幕截图。闭眼检测基于YuNet人脸检测，识别人物闭眼的图片。模糊阈值可选宽松（高方差，仅删除明显模糊）、标准、严格（低方差，删除轻微模糊）三档可调。

扫描时实时显示结果，缩略图网格展示，支持全选或取消选择，也可以单独删除选中的图片。实时显示扫描进度和已发现数量，扫描过程中可以随时终止。发现低质图片之后一键删除，释放存储空间。

这不是在删照片，这是在给你的硬盘减负。

## 操作日志与一键撤回

所有对文件的整理、重命名、清理操作，软件都会完整记录到操作日志里。你可以按日期查看每日摘要，查看详细日志并可复制全部到剪贴板，也可以保存为txt文件，按日期删除日志。日志保留天数可选7天、14天或30天，过期日志自动清理。

任何时候对整理效果不满意，都可以一键全盘撤回所有操作，文件恢复至原始状态。整理五秒钟，撤回一秒钟，这就是我们要的极致安全感。放心大胆地去整理，因为我们永远给你一条退路。

## 为什么是轻羽归档

市面上有大量的文件整理软件，很多采用订阅制收费，一年两三百块，功能却乏善可陈。底层架构老旧，处理几百个文件就开始卡顿。界面功能堆砌，找个设置要翻三层菜单。重复文件识别只靠文件名判断，换个名字就认不出来。更要命的是必须联网上传文件才能使用，你的照片、你的文档，全部要经过别人的服务器。

轻羽归档的差异化非常直接。所有核心功能永久免费开放，无试用时限、无执行次数限制、无广告无弹窗诱导。纯离线运行，无需联网激活、无需登录账号，所有运算在本机完成，数据不出本地。基于Tauri 2构建，安装包体积仅数MB，比Electron应用小了一个数量级，老旧电脑也能流畅运行。

哈希校验基于文件真实内容，不受文件名、格式转换影响，清理更彻底。内置ONNX模型实现本机AI图像与人脸识别，智能分类能力更强。EXIF、GPS、相机参数等敏感信息一键清除，填补大量传统工具的功能空白。完整操作日志配合一键全量撤回，误操作可完全恢复。兼容Windows、macOS、Linux主流操作系统。支持简体中文、繁体中文、English三语国际化。

## 技术架构

轻羽归档采用现代桌面应用架构。前端使用Vue 3 + TypeScript + Element Plus，利用组合式API和响应式UI组件库构建流畅界面。桌面框架使用Tauri 2（Rust），利用系统原生WebView，安装包体积极小，性能远超Electron。构建工具为Vite，提供极速热重载和高效构建。

数据可视化使用ECharts，展示文件类型分布、存储空间统计等图表。AI能力基于ONNX Runtime在本机运行YOLOv8与人脸识别ONNX模型，完全离线推理。底层采用取消令牌模式，长时间运行的任务可随时取消。单实例应用防止重复启动，系统托盘支持最小化到托盘，托盘菜单包含显示或隐藏、打开输出目录、设置、关于、退出。
